# ICQ Web Client

Веб-клиент для ICQ

## Возможности

- Авторизация в ICQ через веб-интерфейс
- Просмотр контактов и групп
- Отправка и получение сообщений в реальном времени
- Индикатор набора текста (typing)
- Управление статусами (Online, Away, DND, Invisible и др.)
- X-статусы (название, описание)
- Загрузка и отображение аватарок
- Поиск пользователей
- Добавление/удаление контактов
- Создание/удаление групп
- Запрос анкеты пользователя
- Регистрация нового аккаунта ICQ
